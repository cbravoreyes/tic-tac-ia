# Clase 1 · TIC, TAC e IA

Recurso educativo de Carlos Bravo Reyes, PhD. © 2026.

## Contenido

Aplicación autónoma para celulares y computadoras: modo claro y oscuro, seis momentos secuenciales, opciones aleatorias, respuestas abiertas con un mínimo de diez palabras e impresión en otra ventana. No requiere dependencias ni compilación.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Descomprime este paquete en tu equipo.
3. Sube index.html, .nojekyll y README.md a la raíz del repositorio (no dentro de otra carpeta).
4. En Settings → Pages, selecciona Deploy from a branch como origen.
5. Selecciona la rama donde subiste los archivos (habitualmente main), carpeta / (root), y guarda.
6. Espera a que GitHub Pages muestre la dirección publicada. Abre ese enlace y comprueba el recorrido.

La disponibilidad de Pages depende de la visibilidad del repositorio y del plan de GitHub. El enlace final lo proporciona GitHub; no es necesario modificar el HTML.

## Usar desde Moodle o WhatsApp

Una vez publicado, añade en Moodle un recurso URL y pega la dirección de GitHub Pages. Puedes compartir esa misma dirección por WhatsApp. Así se abre la aplicación alojada sin pegar código en el editor de Moodle.

## Respuestas e impresión

Las respuestas permanecen únicamente durante la sesión abierta. Recargar o cerrar la página elimina el avance. No se envían respuestas ni calificaciones a Moodle. El botón de impresión abre otra ventana con las respuestas y permite imprimir o guardar como PDF. Si el navegador bloquea esa ventana, permite ventanas emergentes para el sitio.
